# DUDUQ Universal Sync

Human command: **ATUALIZE O CORE** (aliases: SINCRONIZE O CORE, ATUALIZE O DUDUQ, SINCRONIZE O DUDUQ).

Run `npm run duduq:update-core -- --dry-run` without `--component`; this is the official full LIVE Design Graph route. If `READY_TO_APPLY`, run `npm run duduq:update-core -- --apply`. `--component` is diagnostic/advanced scoped mode only. Consumers come from `design-system/penpot-sync/ownership-registry.json`; `NON_CONSUMER` is not validated or changed.
