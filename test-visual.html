📋 Como Testar

  1. Clique em "Testar Agora" para abrir cada jogo em uma nova aba
  2. Interaja com os elementos para ver as animações de hover, clique e feedback
  3. Teste em diferentes tamanhos de tela (redimensione a janela)
  4. Observe os efeitos de glassmorphism, sombras e brilhos
  5. Use F12 (DevTools) para inspecionar as animações e performance
  6. Compare a experiência visual entre as duas mecânicas
